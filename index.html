Using it

          
    
            
  • Click the screen, then type. Keystrokes go through an emulated 8042 controller.
    • 
            
  • Esc clears the demo's screen; Ctrl+Alt+Del reboots the guest.
    • 
            
  • Mouse motion is forwarded to the guest PS/2 mouse.
    • 
            
  • 
              Larger images (a Windows 7 ISO, an installed disk) work too, but need streaming storage: use the
              bring-up shell.
